# cantonrs Homebrew Tap

Official Homebrew tap for [`canton-rs`](https://github.com/cantonrs/canton-rs) — single-binary, zero-JVM Rust runtime for Canton & Splice.

## Install

```sh
brew install cantonrs/tap/canton-rs
```

## Upgrade

```sh
brew upgrade cantonrs/tap/canton-rs
```
